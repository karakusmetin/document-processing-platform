# document-processing-platform
Farklı sistemlerden gelen dokümanları gerçek türünü tespit ederek, yapılandırılabilir dönüşüm profillerine göre güvenli ve doğrulanmış çıktılara dönüştüren; başta PDF gösterim kopyası olmak üzere önizleme ve teknik metadata üreten bağımsız bir Document Conversion &amp; Rendering Platform oluşturmak.
